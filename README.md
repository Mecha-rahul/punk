An architectural, editorial e-commerce experience designed for modern luxury streetwear and limited-drop clothing brands. Inspired by the aesthetics of *Fear of God, Kith, Represent, and Cole Buxton*.

---

## ✨ Key Features

1. **Horizontal-Scroll Editorial Lookbook**
   - Drag & swipe horizontal carousel with mouse-wheel support.
   - Interactive "Shop the Look" hotspots overlaid directly on high-res campaign models.
   - Dynamic slide counters and editorial quote overlays.

2. **Product Catalog & Advanced Filtering**
   - Multi-category navigation (*Hoodies, Tees, Outerwear, Bottoms, Accessories*).
   - Fit Silhouette filtering (*Boxy, Oversized, Relaxed, Cropped*).
   - Real-time stock status badges (`LIMITED DROP`, `SOLD OUT`, `LOW STOCK`).
   - Dual-photo hover flip with colorway swatches and quick add.

3. **Interactive Product Detail View (PDP)**
   - High-res image gallery with horizontal thumbnail selector.
   - Dynamic colorway switcher updating product galleries.
   - Real-time size selection with stock counter.
   - Fabric weight and GSM specifications (e.g. 520 GSM French Terry).
   - Fabric care and garment measurements tabs.

4. **Universal Sizing Chart & Smart Fit Predictor**
   - Interactive slider calculator predicting your exact size based on height (cm) & weight (kg).
   - Imperial (Inches) and Metric (CM) conversion tables.

5. **Slide-Over Shopping Bag & Checkout Flow**
   - Live Free Shipping threshold meter ($150 unlock goal).
   - Promo code coupon system (e.g. `VOID15` for 15% VIP discount).
   - Quantity modifier and instant cart calculations.
   - Express Checkout simulation with Apple Pay / Google Pay / Card feedback.

6. **Drop Countdown & VIP Early Access**
   - Live second-by-second countdown clock for Drop 02.
   - VIP Early Access password signup form.

7. **Multi-Currency Converter**
   - Real-time price conversion between **USD ($)**, **EUR (€)**, **GBP (£)**, and **JPY (¥)**.

8. **Live Search Overlay**
   - Instant search across product titles, descriptions, GSM weights, and fits.

## 🚀 Quick Start

### 1. Instant Zero-Config Preview
You can directly open `index.html` in your browser (double-click or drag into Chrome/Edge/Firefox) — no build or node installation required!

### 2. Run with Node / Vite
```bash
# Navigate to project directory
cd void-studios

# Install dependencies
npm install

# Start local development server
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploy to GitHub / Vercel / Netlify

### Push to your GitHub Repository:
```bash
git init
git add .
git commit -m "feat: Initial VOID STUDIOS luxury streetwear e-commerce build"
git branch -M main
git remote add origin https://github.com/piyushpant-rgb/void-studios.git
git push -u origin main
```

### Deploy to Vercel:
1. Import your GitHub repository into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Click **Deploy**.
