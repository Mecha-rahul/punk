AKUMA placeholder asset folders
===============================

products/     → product photos, referenced from src/data/products.js
categories/   → home page "shop by category" tiles (CategoryShowcase.jsx)
lookbook/     → home page carousel slides (Home.jsx)

hero-placeholder.mp4 / .jpg → Hero section media (Hero.jsx → HERO_SOURCE)

Missing images render a designed "Image coming soon" placeholder
automatically, so the layout stays intentional until real photos land.
